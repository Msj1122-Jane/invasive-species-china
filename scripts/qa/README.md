# QA 回归审计脚本（2026-08-26 深度分析时固化）

> 用途：每次改版后跑一遍，防止回归。前提：项目根目录先起本地服务器 `node scripts/qa/_server.js`（端口 8741），再用 `node scripts/qa/<脚本>` 执行。

| 脚本 | 检查内容 |
|---|---|
| `_server.js` | 本地静态服务器（8741 端口，无缓存） |
| `_audit.js` | 控制台错误 / 页面错误 / 断图 / 横向溢出 / 章节结构 / 逐幕截图 |
| `_textaudit.js` | 全文标题、KPI 计数器、图表脚注、正文段落抽取（人工核对文案一致性） |
| `_interact.js` | KPI 数字滚动终值、开箱卡翻转、375px 移动端无横向溢出 |
| `_postertest.js` | 家乡查询省份下拉、结果卡、海报生成（900×1200 + 下载）冒烟 |
| `_datacheck.js` / `_datacheck2.js` | 数据文件统计核验（180 种分类、92.6% 异宠占比、341 名录美洲占比等） |
| `_finalcheck.js` | 方法页加载、字体状态、页面总传输体积、大资源清单 |
